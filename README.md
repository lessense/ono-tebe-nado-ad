## О проекте

Учебная проектная работа: адаптированная под ноутбуки (ширина `1100px`) одностраничная вёрстка сайта аукциона «Оно тебе надо» по макету из Figma. Проект сделан по методу **прогрессивного джипега** — сначала собрана вся структура страницы, затем секции доведены до деталей.

## Что внутри страницы

| Секция | Что реализовано |
| --- | --- |
| **Шапка** | Грид `1fr min-content 1fr`: меню с маркерами, логотип по центру, блок контактов (`tel:`, `mailto:`) |
| **Обложка** | Фон с переиспользуемым оверлеем, заголовок `h1` из трёх выровненных строк, подзаголовок и кнопка «Сделать ставку» |
| **Лоты** | Список карточек на флексбоксе с переносом строк, фоновые изображения, общий класс оверлея |
| **Об аукционе** | Двухколоночный грид, чёрный круглый контейнер с логотипом, два абзаца с гибким `gap` |
| **Подвал** | Грид из трёх колонок: адрес, меню по центру, иконки соцсетей |

## Технологии и подходы

- Семантическая HTML-разметка: `header`, `nav`, `main`, `section`, `article`, `address`, `footer`
- Методология **БЭМ** для именования классов (`block__element_modifier`)
- Сетки на **CSS Grid** и **Flexbox**, отступы через `gap`
- Шрифт **Raleway** (WOFF2 → WOFF), подключение через `@font-face`
- Абсолютное позиционирование только там, где оно оправдано (оверлей)
- Без инлайновых стилей и без фиксированной высоты там, где её можно не задавать

## Структура проекта

```text
ono-tebe-nado/
├── fonts/
│   ├── fonts.css          # подключение шрифта Raleway
│   └── Raleway-*.woff(2)
├── images/                # фоны, карточки, логотипы, иконки соцсетей
├── styles/
│   ├── global.css         # сброс отступов и общие стили
│   └── style.css          # стили страницы
├── index.html
└── README.md
```

Порядок подключения стилей: шрифты → глобальные стили → локальные стили.

## Запуск

Сборка не нужна. Достаточно открыть `index.html` в браузере (все пути относительные, LiveServer не требуется).

```bash
git clone https://github.com/lessense/ono-tebe-nado-ad.git
cd ono-tebe-nado-ad
```

## Автотесты

Репозиторий должен быть **публичным**. При каждом пуше GitHub Actions запускает проверку по чек-листу: валидность HTML, семантика, именование классов и скриншотное сравнение с макетом. Результаты — во вкладке **Actions**.
